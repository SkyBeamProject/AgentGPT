# Overview

AgentGPT lets you assemble, configure, and deploy autonomous AI agents in the browser — name an agent, give it a goal, and it iteratively plans, executes, and learns from tasks. The stack is a Next.js 13 + TypeScript frontend and a FastAPI backend, with Prisma/SQLModel on MySQL, NextAuth for auth, TailwindCSS for styling, and LangChain for LLM tooling. A bundled setup CLI wires up env vars, database, backend, and frontend for local development.
